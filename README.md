# 心动配对前端原型

这是一个用 `Vite + React + Tailwind CSS` 初始化好的前端项目，已经替换成适合“找对象软件”继续扩展的原型页面。

## 已包含内容

- React 工程脚手架
- Tailwind CSS 样式体系
- 组件化页面结构
- 模拟推荐用户数据
- 首页、推荐卡片、聊天预览、后续扩展提示

## 本地启动

先安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

打包生产版本：

```bash
npm run build
```

本地预览打包结果：

```bash
npm run preview
```

## 项目结构

```text
src/
  components/   页面组件
  data/         模拟数据
  App.jsx       页面组合入口
  main.jsx      React 挂载入口
  index.css     Tailwind 与全局样式
```
